## Recent Updates

Stay informed about the latest enhancements to Profit Engineer. We release updates regularly to improve profit analysis, channel integrations, and actionable insights from your marketing data.

<Update label="2024-10-15" description="v1.3.0" tags={["feature", "improvement"]}>
## New Features

- Added AI-powered profit forecasting for the next 7 days based on current channel performance.
- Introduced Google Ads integration with automatic retargeting analysis.

## Improvements

- Enhanced Meta Ads recommendations with 22% more accurate profit attribution.
- Dashboard now loads `<2s` even with high-volume data.

## Bug Fixes

- Fixed occasional miscalculation in cost-per-customer metrics.
- Resolved webhook delivery failures during peak hours.
</Update>

<Update label="2024-09-20" description="v1.2.0" tags={["feature", "bugfix"]}>
## New Features

- Real-time alerts for channels dropping below profit targets.
- Customizable weekly action summaries via email.

## Improvements

- Optimized data processing for larger ad accounts (`>50` campaigns).

## Bug Fixes

- Corrected broad ad set detection logic.
- Fixed export issues with CSV profit reports.
</Update>

<Update label="2024-08-10" description="v1.1.0" tags={["feature", "breaking"]}>
## New Features

- Core Mythic OS dashboard with daily profit breakdowns.
- Initial Meta Ads profit tracking and recommendations.

## Breaking Changes

- Updated API endpoints to use `https://api.profitengineer.ai/v2`.

## Bug Fixes

- Improved handling of zero-profit campaigns.
</Update>

## Upgrade Instructions

<Steps>
  <Step title="Check Current Version" icon="check-circle">

  </Step>
  <Step title="Update Integrations" icon="refresh-cw">
    
````bash
# Update your webhook URL if using v1 endpoints

````

## API Changes Summary

Review key code updates for integrations.

<CodeGroup tabs="JavaScript,Python">
````javascript
// New v2 endpoint for profit data
const response = await fetch('https://api.profitengineer.ai/v2/profit', {
  headers: { Authorization: `Bearer ${YOUR_API_KEY}` }
});
const data = await response.json();
console.log(data.channels); // Array of channel profits
````

````python
# New v2 endpoint for profit data
import requests
response = requests.get(
    'https://api.profitengineer.ai/v2/profit',
    headers={'Authorization': f'Bearer {YOUR_API_KEY}'}
)
data = response.json()
print(data['channels'])  # List of channel profits
````
</CodeGroup>

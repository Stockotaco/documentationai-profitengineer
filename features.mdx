## Overview

Profit Engineer delivers actionable insights from your marketing data, turning complex numbers into plain English recommendations. You receive daily reports that highlight profit drivers, cost inefficiencies, and precise next steps. Core features include automated reports, channel breakdowns, recommendations, profit metrics, and custom alerts.

## Daily Plain-English Reports

Every day, Profit Engineer analyzes your marketing data and sends a concise report. You get insights without dashboards or manual analysis.

<Callout kind="tip">
  Reports arrive via email or your dashboard by 8 AM, covering the previous day's activity.
</Callout>

Example report content:

```
Kept this week: $18,240 ▲ 22% vs last week
Cost to get a customer: $41 ▼ $7 this week
```

## Custom Alert Setup

Configure alerts for metrics crossing your thresholds.

<Steps>
  <Step title="Access Settings" icon="settings">
    Navigate to your dashboard settings.
  </Step>
  <Step title="Define Thresholds" icon="sliders">
    Set rules like "Alert if CAC > $50".
  </Step>
  <Step title="Choose Delivery" icon="bell">
    Select email, Slack, or in-app notifications.
  </Step>
</Steps>

<CodeGroup tabs="JSON,Webhook">
  ```json
  {
    "alerts": [
      {
        "metric": "cac",
        "threshold": 50,
        "operator": "gt",
        "channel": "email"
      }
    ]
  }
  ```
  ```javascript
  // Webhook payload example
  await fetch('https://your-webhook-url.com/alert', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      metric: 'cac',
      value: 52,
      action: 'review'
    })
  });
  ```
</CodeGroup>

<Expandable title="Advanced Metrics Configuration" default-open="false">
  Integrate custom profit formulas via API.

  <ParamField path="profit_formula" param-type="string" required="true">
    JavaScript expression for custom calculations, e.g., `(revenue - costs) * margin`.
  </ParamField>

  Example API call to `https://api.example.com/v1/metrics`:

  ```bash
  curl -X POST https://api.example.com/v1/metrics \
    -H "Authorization: Bearer YOUR_API_KEY" \
    -d '{"profit_formula": "(revenue - ad_spend - ops_cost) * 0.3"}'
  ```
</Expandable>

<Callout kind="info">
  Start with default metrics, then customize as your business scales.
</Callout>
